# Reading Room: shared work

Mode: Operate / Read. User-selected direction: Reading Room (second displayed concept), with an open triangle, warm light lilac and a proposed copper-on-ink dark mode. The user subsequently authorized implementation and iteration of the shared-intelligence interactions.

THESIS: One room carries conversation, saved working documents and the work that produced an artifact. People can write, ask about an exact snapshot, and review the actual resulting content.

OWN-WORLD: A working reading room. Paper/ink planes, compact labeled navigation and editorial document typography; the artifact carries the emphasis. Keep meaningful scope, source restrictions and actual task state legible. Avoid atmospheric wallpaper, decorative blobs and omniscient activity feeds.

STORY: Enter Home's living brief; open a shared channel; follow named work; open or edit its document; ask Aksara about a scoped snapshot; review the exact document and destination. An optional shared table arranges real Library sources and hands a bounded request into that room.

FIRST VIEWPORT: Desktop document view keeps navigation and the same-room conversation beside a complete working document. A save state and readable title are visible; the review action stays at the document's bottom edge. On phones the document fills the screen and preserves writing space. Home is its own view, not a permanent third column.

FORM: Inter Variable for controls; Georgia for document paragraphs. Warm white / lilac in light; graphite / copper in dark. Flat planes, hairline boundaries, 8–12px control shapes; small interruptible 200–240ms movement, reduced motion respected. Desktop nav left edge stays fixed.

QUALITY BAR: The selected concept is the structural and typographic reference, adapted to real backend content and controls. No fabricated work or contributor identity. A review binds a frozen source snapshot. Draft conflicts preserve unsaved text; exports never silently use an external asset proxy. Preview content is explicitly fictional and tab-local. Modest hardware has no mandatory shader.
