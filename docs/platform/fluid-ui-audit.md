# Fluid workspace UI audit

Requalified 30 October 2026 (Asia/Bangkok). Applies the installed Taste v2 **app-screen** route to the
approved Octopus/shadcn/Cult direction. The old OpenDuet fidelity audit describes
a previous checkpoint.

The browser inspector checked 1440, 768 and 390 px, local fonts, dark graphite,
text contrast, horizontal overflow, shadows, gradients and layout. Its final
report has **zero failures and zero warnings**. The only explicit allowance is
`purple`, because lilac is the user's chosen brand accent. There is no allowance
for heavy shadows, glass, tiny text or a large empty hero.

[Desktop](ui-audit/fluid-desktop.jpg) · [Phone](ui-audit/fluid-mobile.jpg).
These captures use disposable sample data and do not imply a live cloud backend.

The implementation replaces the narrow phone column with a wide inset canvas,
keeps the sidebar collapsed initially, embeds the composer on Today, and uses
flat tone steps. Secondary labels are readable, typography scales with root
text size, and unknown-duration work has no fabricated completion percentage.
The source/resource renderer has a narrow host port and re-reads current access.

Behavioral checks cover a keyboard-contained mobile drawer, Escape/restoration,
200% text size, embedded draft continuity, scoped generated resource cards,
private/shared and personal custody switches, canonical conversations, source
withdrawal, exact approvals, receipts and simulator output. A split document
context pane retains its form while resizing. Motion respects reduced-motion
preferences; scope changes unmount restricted content immediately.

Onboarding uses the actual Cult wizard. Model connection choices do not imply
successful inference: a canonical test turn checks the connection, keyless quota
failures stay failures, and saved Codex sign-in is distinguished from a working
model response. Live ChatGPT account completion remains to be exercised by its
owner; no account credential was borrowed from this execution environment.

The final follow-on checkpoint passes 17 disposable-preview browser checks,
14 real-host product checks and 8 privacy/approval smoke checks. Source withdrawal
also closes an open review derived from that source; keyboard submission cannot
bypass the hosted-turn consent control. The native Mastra gateway/runtime suite
passes 27 checks with the optional real-Docker qualification enabled. The Docker
port remains observation-only groundwork, not a completed agent computer.
