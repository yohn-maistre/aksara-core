# Atmospheric workspace checkpoint

30 October 2026 (Asia/Bangkok). Implements the user-selected generated Home,
Library and thread direction, including the later smoked-background and regular
full-height spine refinements.

## What works

- Home sits directly on a generated smoked raster; it contracts into a companion
  beside the active workspace. Its panel choices and calendar position survive
  navigation within the same authorized context. Smaller screens show one primary
  view. A channel/custody change remounts restricted content immediately.
- The regular, higher-opacity navigation spine expands from its top mark. Profile,
  appearance and settings live at its foot. Shared channels branch below Channels.
  Expansion is a harmless presentation preference and survives channel changes;
  old content, model choices, drafts, approvals and pins do not.
- One composer is active across Home, Library, capabilities and conversations.
  Source/model choices live behind its plus control. Sending from another view
  opens the current conversation. Existing per-turn hosted consent and source
  exclusion remain enforced. An arriving reply preserves a different follow-up
  draft typed during that turn.
- Private and shared conversations use the same adapted Cult speech-bubble
  primitives. Reply actions are in a menu: local read-aloud, turn into a reviewed
  document, or pin to Home. The work area shows actual authorized work, source
  links and status; it does not manufacture tool traces or computer screenshots.
- Up to four accepted assistant messages can be pinned as tab-local Home panels.
  Pins store sequence references, not copied content. Rendering uses current
  eligible messages and the existing bounded OpenUI/SurfacePort. Withdrawal,
  access failure or custody changes remove dependent panels. Hidden compact Home
  views do not mount pinned resource renderers on phones.
- Library separates reviewed knowledge excerpts from files/documents. File
  collections, name/recent sorting, title filtering, authorized content search,
  original-source import and exact document creation remain functional. Knowledge
  cards open their eligible originals; withdrawn evidence disappears. Document
  categorization uses existing host provenance as presentation metadata, never
  as a grant or proof of a stronger review policy.
- Capability Packs expose their validated screen destinations through host-owned
  navigation. A screen or manifest still creates no tool/execution right.
- The work surface scrolls above its composer. Phone layout uses dynamic viewport
  height, safe-area spacing and Android keyboard resize metadata. Read-only
  history has no composer. The calendar navigates real recorded work snapshots.

## Materials and reuse

Graphite, lilac and warm semantic roles support dark/light appearances. Fonts
remain self-hosted Inter Variable; existing Lucide icons match the selected
outline grammar. The background is a generated 1280-pixel WebP (6,898 bytes),
not copied reference imagery. Its slow transform pauses in hidden tabs, with
reduced motion, or through the profile menu. The new public raster joins the
public-only PWA shell cache; API, identity, document and audio caching stays off.
Theme-color and launch background follow the graphite defaults.

The actual Cult speech-bubble registry source is installed and adapted from
its h1/display wrapper to ordinary prose semantics. Optional decorative cursor
and SVG tail are not used in normal messages. Existing Base UI menus/dialogs,
shadcn sidebar and Octopus surface/pane primitives remain. No Gooey, shader,
weather provider or extra UI runtime dependency is introduced in this checkpoint.
The regular rail follows the user's explicit refinement.

## Qualification and limits

The product browser suite passes 19 real-host checks, including source withdrawal
of both reviewed knowledge and pinned generated panels, draft preservation,
canonical model replies, exact approvals, receipts and shared/personal isolation.
The disposable preview passes 21 checks, including file collections, panel
continuity, channel branches, keyboard drawer behavior, phone/200% text layout,
no external/API data requests and the Pages guard. Eight existing privacy/approval
smoke checks pass. Captured dark/light desktop and phone flows have no console
errors. See the root `design-qa.md` and [current audit](atmospheric-ui-audit.md).

The calendar is the latest update for up to 100 currently eligible work items,
not a complete activity archive, scheduled calendar service or productivity score.
Knowledge cards are reviewed excerpts; automatic company-wiki synthesis and a
richer ontology/graph remain future projections. Home layout/pins are tab-local,
not durable shared layout editing. Generated UI remains the existing bounded
registered profile; arbitrary HTML/JavaScript and automatic UI mutations are not
enabled. Weather synchronization, microphone capture, interactive computers,
persistent computer workspaces and durable subagent/tool recovery remain gated.
No Surface Pro or A12 timing/battery/thermal result is claimed. Pages continues
to host a clearly labeled UI preview, separately from the real local Rust host.
